# SWMconvert-1.95b #
####################

Hermit has released SWMconvert-1.95b, a new command-line tool designed to
convert compositions from SID-Wizard SWM format into GoatTracker SNG files,
with optional compatibility for workflows like NinjaTracker.

This new version is a fully hand-coded implementation. It aims to preserve many
SID-Wizard-specific composition features while producing the more compact output
format used by GoatTracker. However, some effects cannot be translated due to
limitations in the target format.

The goal is to combine the usability and feature richness of SID-Wizard during
composition with the smaller exported file sizes of GoatTracker-based workflows.

The release includes builds for Linux (Intel 32-bit and 64-bit) and ARM
(Raspberry Pi Zero, 32-bit soft-float). The author notes that the tool has
minimal dependencies beyond the C standard library, making it easy to compile on
other systems, including Windows.

The tool can be found here: https://csdb.dk/release/?id=262049

# FlexSID 1.4 #
###############

FlexSID is a music editor made by Mihaly Horvath (Hermit). FlexSID is primarily
a tool for you to create small footprint SID music. Yet it provides flexibility
and most features you usually need for good sound.

To reach this goal it's a bit different conceptually from the traditional music
trackers: diatonic scale-degree based notation system for better music-data
compression where it is possible, and the single command-oriented
instrument-table which is responsible for the small player-code size. The result
pretty much depends on the musician as well.

The editor is written in C (and some ca65 assembly), compiled with cc65 and gcc
with a quasi-emulated layer on top of SDL1.2, and therefore runs identically on
Linux (compiled for 64bit) and of course C64.

The following has been changed since 1.2:

- Exported PRG/SID can be re-imported (partial data loss)
- SID/display emulation optimized for Raspberry Pi Zero and slow CPUs
- Uses compress64k-v1.2 for faster startup, slightly larger executables
- Added Shogoon .flx examples (with permission)
- Various display and user manual fixes and improvements
- FlexSID improved ARM support for low-power devices (EEEPC, Pi, etc.)
- Three FlexSID variants added with different zeropage usage trade-offs
- Linux release: single FlexSID executable with CLI/symlink variants
- Includes tutorials folder for learning and composing tiny intro tunes

Check it out: https://csdb.dk/release/?id=260718

# SIDM2conv v3.4.1 #
####################

Michael Troelsen released a new version of the SID to SID Factory II Converter,
bringing a major update to a Python-based tool that converts Commodore 64 .sid
music files into SID Factory II .sf2 project files.

Wilfred Bos has released a new version of SID Known. This version supports now
