# HVSC — unofficial GitHub mirror

An unofficial GitHub mirror of the [High Voltage SID Collection](https://www.hvsc.de/), a collection of Commodore 64 SID music maintained by the HVSC team and its contributors. This repository is not affiliated with or endorsed by HVSC.

Initial snapshot: HVSC #85, released 28 June 2026, obtained from the [HVSC-listed Danish mirror](https://hvsc.brona.dk/HVSC/HVSC_85-all-of-them.7z). The official [downloads page](https://hvsc.de/downloads) lists current releases and invites mirrors.
